Ringkasan Rumus Penting SMA

Referensi cepat materi ujian matematika kelas X, XI, dan XII.

Kelas X

Eksponen & Logaritma

  • • \(a^m \cdot a^n = a^{m+n}\)
  • • \((a^m)^n = a^{m \cdot n}\)
  • • \(^a\log(b \cdot c) = ^a\log b + ^a\log c\)
  • • \(^a\log(b^n) = n \cdot ^a\log b\)
Kelas XI

Turunan Fungsi

  • • \(f(x) = a x^n \implies f'(x) = a \cdot n x^{n-1}\)
  • • Aturan Perkalian: \((u \cdot v)' = u'v + uv'\)
  • • Aturan Pembagian: \(\left(\frac{u}{v}\right)' = \frac{u'v - uv'}{v^2}\)
  • • Turunan Trigonometri: \(\frac{d}{dx}(\sin x) = \cos x\)
Kelas XI / XII

Integral Tak Tentu

  • • \(\int x^n \, dx = \frac{1}{n+1} x^{n+1} + C\)
  • • \(\int a \, dx = ax + C\)
  • • Integral Substitusi: \(\int f(g(x)) g'(x) dx\)
  • • \(\int \cos x \, dx = \sin x + C\)
Kelas XI

Matriks & Determinan

  • • \(\det(A) = ad - bc\)
  • • Invers: \(A^{-1} = \frac{1}{\det(A)} \begin{pmatrix} d & -b \\ -c & a \end{pmatrix}\)
  • • \((AB)^{T} = B^T A^T\)
Kelas X / XI

Identitas Trigonometri

  • • \(\sin^2 x + \cos^2 x = 1\)
  • • \(\sin(2x) = 2 \sin x \cos x\)
  • • \(\cos(2x) = \cos^2 x - \sin^2 x\)
  • • \(\tan x = \frac{\sin x}{\cos x}\)
Kelas XII

Statistika Dasars

  • • Rata-rata (\(\bar{x}\)): \(\frac{\sum x_i}{n}\)
  • • Ragam/Varians (\(s^2\)): \(\frac{\sum (x_i - \bar{x})^2}{n}\)
  • • Simpangan Baku: \(s = \sqrt{s^2}\)
